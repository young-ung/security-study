# Linux 02. 파일 검색과 내용 확인

## 1. 오늘 학습 내용

Linux에서 파일과 디렉터리를 검색하고, 파일의 내용을 확인하는 명령어를 실습했다.

---

## 2. grep

`grep`은 파일 안에서 원하는 문자열을 검색한다.

```bash
grep "Linux" test.txt
```

`test.txt`에서 `Linux`가 포함된 줄을 검색한다.

### -i

`ignore`의 의미로, 대소문자를 구분하지 않고 검색한다.

```bash
grep -i "linux" test.txt
```

`Linux`, `linux`, `LINUX` 등을 모두 검색할 수 있다.

### -n

검색 결과에 줄 번호를 표시한다.

```bash
grep -n "Linux" test.txt
```

---

## 3. find

`find`는 파일이나 디렉터리 자체를 검색한다.

기본 구조:

```bash
find [검색 시작 위치] [조건]
```

### 현재 디렉터리에서 검색

`.`은 현재 디렉터리를 의미한다.

```bash
find . -name "test.txt"
```

현재 디렉터리부터 `test.txt`를 찾는다.

### 확장자로 검색

`*`는 어떤 문자열이든 될 수 있음을 의미한다.

```bash
find . -name "*.txt"
```

현재 디렉터리부터 `.txt`로 끝나는 파일을 찾는다.

### 파일만 검색

`f`는 `file`을 의미한다.

```bash
find . -type f
```

파일만 검색한다.

### 디렉터리만 검색

`d`는 `directory`를 의미한다.

```bash
find . -type d
```

디렉터리만 검색한다.

### 여러 조건 사용

조건을 여러 개 조합할 수 있다.

```bash
find . -type f -name "*.txt"
```

현재 디렉터리부터

- 파일이고
- `.txt`로 끝나는

항목만 검색한다.

## 4. 경로 기호

```text
.    현재 디렉터리
..   부모 디렉터리
~    홈 디렉터리
/    루트 디렉터리
```

예:

```bash
find . -name "*.txt"
```

현재 디렉터리부터 `.txt` 파일을 검색한다.

---

## 5. head

`head`는 파일의 앞부분을 확인한다.

```bash
head test.txt
```

기본적으로 앞에서 10줄을 보여준다.

### 줄 수 지정

```bash
head -n 2 test.txt
```

앞에서 2줄만 보여준다.

`-n`은 `head`와 `tail`에서 출력할 줄 수를 지정하는 옵션이다.

---

## 6. tail

`tail`은 파일의 뒷부분을 확인한다.

```bash
tail test.txt
```

기본적으로 뒤에서 10줄을 보여준다.

### 줄 수 지정

```bash
tail -n 2 test.txt
```

뒤에서 2줄만 보여준다.

```text
tail       → 뒤에서 기본 10줄
tail -n 5  → 뒤에서 5줄
```

---

## 7. less

`less`는 긴 파일의 내용을 화면 단위로 확인할 때 사용한다.

```bash
less test.txt
```

문서를 화면에서 이동하며 확인할 수 있다.

주요 조작:

```text
↑ / ↓   한 줄 이동
Space   다음 화면
b       이전 화면
q       종료
```

---

## 8. 옵션

명령어 뒤에 붙는 `-`는 옵션을 나타내는 표시로 이해할 수 있다.

예:

```bash
grep -i "linux" test.txt
```

```text
grep → 명령어
-i   → 옵션
```

```bash
find . -type f
```

```text
find  → 명령어
.     → 검색 시작 위치
-type → 옵션
f     → file
```

옵션의 의미는 명령어에 따라 달라질 수 있으므로 명령어별로 이해해야 한다.

---

## 9. 오늘 배운 명령어 정리

```text
grep  → 파일 내용 검색
find  → 파일 / 디렉터리 검색
head  → 파일 앞부분 확인
tail  → 파일 뒷부분 확인
less  → 긴 파일 내용 확인
```

### grep과 find의 차이

```text
grep → 파일 안의 내용 검색
find → 파일 / 디렉터리 자체 검색
```

### head와 tail의 차이

```text
head → 앞부분
tail → 뒷부분
```
