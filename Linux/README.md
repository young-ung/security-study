# Linux Study
## 1. 기본 명령어

### pwd
현재 작업 중인 디렉터리의 경로를 확인한다.

### ls
현재 디렉터리의 파일과 폴더를 확인한다.

### cd
디렉터리를 이동한다.

### mkdir
새로운 디렉터리를 만든다.

### touch
새로운 파일을 만든다.

### cp
파일이나 디렉터리를 복사한다.

### mv
파일이나 디렉터리를 이동한다.
같은 디렉터리에서 사용하면 파일 이름을 변경할 수도 있다.

### rm
파일이나 디렉터리를 삭제한다.

### cat
파일의 내용을 터미널에 출력한다.

## 2. 파일 및 디렉터리 관리

### mkdir
디렉터리를 생성한다.

### touch
파일을 생성한다.

### cp
파일이나 디렉터리를 복사한다.

### mv
파일이나 디렉터리를 이동한다.
같은 위치에서 사용하면 이름을 변경할 수 있다.

### rm
파일을 삭제한다.

### cd ..
현재 디렉터리에서 상위 디렉터리로 이동한다.

### cd ~
홈 디렉터리로 이동한다.

## 3. 파일 내용 다루기

### cat
파일의 내용을 출력한다.

### echo
문자열을 출력한다.

### >
출력 결과를 파일에 저장한다.
기존 내용이 있으면 덮어쓴다.

### >>
출력 결과를 파일에 추가한다.
기존 내용은 유지된다.

### 예시

echo "hello linux" > test.txt
cat test.txt

## 4. 파일 권한

### 권한의 종류

- `r` (read) — 읽기
- `w` (write) — 쓰기
- `x` (execute) — 실행

### 권한의 대상

- `owner` — 파일 소유자
- `group` — 파일이 속한 그룹
- `others` — 그 외 사용자

### 권한 구조

owner | group | others

### 숫자 권한

- `r` = 4
- `w` = 2
- `x` = 1

예시:

`rwx` = 4 + 2 + 1 = 7

`rw-` = 4 + 2 = 6

`r--` = 4

`---` = 0

## 5. 권한 변경

### chmod
파일이나 디렉터리의 권한을 변경한다.

### 예시

**`chmod 700 secret.txt`**  

700은 소유자에게 읽기, 쓰기, 실행 권한을 부여한다.  
그룹과 기타 사용자에게는 권한을 부여하지 않는다.

**`chmod 600 secret.txt`**

600은 소유자에게 읽기, 쓰기 권한을 부여한다.  
그룹과 기타 사용자에게는 권한을 부여하지 않는다.

## 6. 소유자 및 그룹 변경

### chown

파일이나 디렉터리의 소유자를 변경한다.

`chown alice secret.txt`

→ `secret.txt`의 소유자를 `alice`로 변경한다.

### chgrp

파일이나 디렉터리의 그룹을 변경한다.

`chgrp security secret.txt`

→ `secret.txt`의 그룹을 `security`로 변경한다.

## 7. sudo

### sudo

일반 사용자가 관리자(root) 권한으로 명령어를 실행할 때 사용한다.

`sudo chmod 600 secret.txt`

→ 관리자 권한으로 `secret.txt`의 권한을 변경한다.

### 언제 사용하는가?

현재 로그인한 사용자가 해당 작업을 수행할 권한이 없을 때 사용한다.

예를 들어 시스템 파일을 수정하거나 다른 사용자의 파일에 접근하는 등의 작업에는 관리자 권한이 필요할 수 있다.

> **주의:** `sudo`는 강력한 권한을 부여하므로 필요한 명령어에만 사용하는 것이 좋다.
