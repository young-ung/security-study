# Linux 03. 프로세스와 파이프

## 1. 오늘 학습 내용

오늘은 Linux에서 파일 내용을 검색하는 방법을 복습하고, 명령어의 결과를 다른 명령어로 전달하는 파이프(`|`)와 실행 중인 프로세스를 확인하는 `ps` 명령어를 학습했다.

---

## 2. less 검색

`less`는 파일의 내용을 화면 단위로 확인할 때 사용하는 명령어이다.

`less test.txt`

파일을 연 상태에서 `/`를 사용하면 원하는 문자열을 검색할 수 있다.

`/Linux`

검색 관련 명령어:

`/Linux` → Linux 검색  
`n` → 다음 검색 결과  
`N` → 이전 검색 결과  
`q` → less 종료

---

## 3. 파이프 (|)

`|`는 파이프라고 하며, 앞 명령어의 결과를 뒤 명령어에게 전달한다.

기본 구조:

`명령어1 | 명령어2`

예:

`ls | grep txt`

실행 과정:

`ls`
↓
현재 디렉터리의 목록 출력
↓
`|`
↓
`grep txt`
↓
txt가 포함된 결과만 출력

즉,

`ls` → 목록을 보여줌  
`grep` → 원하는 결과를 골라냄

파이프를 사용하면 여러 명령어를 연결할 수 있다.

---

## 4. ps

`ps`는 `process status`의 의미로, 현재 실행 중인 프로세스를 확인할 때 사용한다.

`ps`

프로세스는 현재 실행되고 있는 프로그램이나 작업을 의미한다.

---

## 5. ps aux

`ps aux`는 프로세스를 더 넓고 자세하게 확인할 때 사용한다.

`ps aux`

`aux`는 하나의 단어라기보다 `a`, `u`, `x` 옵션을 조합한 것이다.

### a

다른 사용자의 프로세스도 포함한다.

`a` → 다른 사용자 프로세스 포함

### u

사용자 중심의 상세한 정보를 표시한다.

`u` → user 정보 중심

### x

터미널에 연결되지 않은 프로세스도 포함한다.

`x` → 터미널 없는 프로세스 포함

정리:

`a` → 다른 사용자 포함  
`u` → user 중심 상세 정보  
`x` → 터미널 없는 프로세스 포함

---

## 6. ps aux와 grep 조합

파이프를 이용하면 프로세스 목록에서 원하는 프로세스만 골라낼 수 있다.

`ps aux | grep bash`

실행 과정:

`ps aux`
↓
전체 프로세스 정보를 넓게 확인
↓
`|`
↓
`grep bash`
↓
bash가 포함된 줄만 출력

즉,

`ps aux` → 프로세스 목록 확인  
`grep` → 원하는 내용 검색  
`|` → 결과 전달

---

## 7. grep -v

`-v`는 `invert`의 의미로, 검색 결과를 반전한다.

`grep "Linux" test.txt`

→ `Linux`가 포함된 줄을 출력한다.

`grep -v "Linux" test.txt`

→ `Linux`가 포함되지 않은 줄을 출력한다.

### grep 옵션 정리

`-i` → ignore → 대소문자 무시  
`-n` → number → 줄 번호 표시  
`-v` → invert → 검색 결과 반전

---

## 8. grep을 여러 번 사용하기

파이프를 이용하면 `grep`을 여러 번 연결할 수 있다.

`ps aux | grep bash | grep -v grep`

실행 과정:

`ps aux`
↓
전체 프로세스 목록
↓
`grep bash`
↓
bash가 포함된 줄만 검색
↓
`grep -v grep`
↓
grep이 포함된 줄은 제외

여기서 `grep -v grep`은 하나의 명령어이다.

구조:

`grep` → 명령어  
`-v` → 옵션  
`grep` → 검색할 문자열

---

## 9. 오늘 배운 핵심

### 명령어 정리

`less` → 파일을 화면 단위로 확인  
`/Linux` → less에서 문자열 검색  
`n` → 다음 검색 결과  
`N` → 이전 검색 결과  
`q` → less 종료

`|` → 앞 명령어의 결과를 뒤 명령어로 전달

`ps` → process status → 프로세스 확인

`ps aux`

`a` → 다른 사용자 프로세스 포함  
`u` → user 중심 상세 정보  
`x` → 터미널 없는 프로세스 포함

`grep -i` → ignore → 대소문자 무시  
`grep -n` → number → 줄 번호  
`grep -v` → invert → 검색 결과 반전

오늘은 `less` 검색부터 시작해서 파이프(`|`), `ps`, `ps aux`, `grep -v`까지 학습했다.

특히 다음 명령어를 통해 여러 명령어를 연결하는 방법을 이해했다.

`ps aux | grep bash`

→ 프로세스 목록에서 `bash`가 포함된 항목을 검색한다.

`ps aux | grep bash | grep -v grep`

→ `bash`가 포함된 프로세스를 검색한 뒤 `grep` 자체가 포함된 줄은 제외한다.
